## AI Integration — Architecture Note

When Phase 4 begins, the recommended setup:

```
User query
  → Next.js Server Action (route handler)
    → Build context: fetch user's last 30 transactions from Firestore
    → Call Claude API with context + user message
    → Stream response back to chat panel
```

Model recommendation: **claude-sonnet-4-6** for chat (speed + cost), **claude-opus-4-7** for monthly reports (depth).  
Tools to enable: `read_transactions`, `create_transaction`, `update_goal` as Claude tool-use functions.
